# DLV Automation — Google-only SEO: мониторинг и контроль трафика

Актуализировано 12 октября 2026. Сайт: https://dlvautomation.ru/. Репозиторий: `Rbastl/dlv-automation`.

**Решение:** работаем с Google. Яндекс API намеренно отключён (`DLV_YANDEX_ENABLED=false`); возобновлять без отдельного решения не нужно. Ранее проверенные доступы Google заново не запрашивать и не пересоздавать.

## 1. Автоматическая диагностика сайта

- `.github/workflows/seo-public-monitor.yml` → `scripts/seo_monitor.py`.
- Ежедневная проверка всех опубликованных URL, HTTPS, robots.txt, sitemap.xml, title, H1, canonical, robots indexable.
- При изменении кода sitemap или монитора проверка запускается после push в `main`.
- Публичный sitemap сравнивается с файлом в GitHub: устаревший Netlify-deploy не считается успешной проверкой.
- Отдельная задача раз в неделю отслеживает изменения публичных страниц конкурентов из `seo/competitors.json`; учёт robots.txt, без обхода ограничений.
- Последняя проверка **до текущего спринта** (12 октября, run 38254615224): 39/39 URL доступны, ошибок 0. Новый план требует проверку 40/40 после публикации `/uslugi/`.

## 2. Настоящий поисковый трафик Google

- `.github/workflows/seo-search-analytics.yml` → `scripts/seo_search_analytics.py`: по понедельникам, ~09:23 Новосибирск.
- Доступ к Search Console с правом **чтения**, запись только в закрытую Google-таблицу.
- `Сводка`: суммарные клики, показы, CTR, средняя позиция по всему сайту (включая скрытые/анонимные Google поисковые запросы, насколько их включает итоговая статистика).
- `Страницы`: показатели по каждому доступному URL без привязки к тексту запроса.
- `Google`: пары запрос + страница; такие строки могут быть неполными из-за анонимизации поисковых запросов.
- Другие старые вкладки сохранены для истории.

## 3. Статусы индексирования каждого URL

- `.github/workflows/google-index-coverage.yml` → `scripts/google_index_audit.py`.
- Еженедельно по вторникам ~09:47 Новосибирск и при изменениях `sitemap.xml` или скрипта.
- Использует тот же действующий Google service account и разрешение `webmasters.readonly`.
- Сравнивает каждую страницу из sitemap с **индексированной версией** в Search Console URL Inspection API.
- Детали URL, статус PASS/NEUTRAL/FAIL, доступность Googlebot, robots, canonical, последний обход записываются только в закрытую вкладку `Индексация`. В публичный workflow summary попадают только агрегаты.
- **Не отправляет** запросы на принудительную индексацию, не обходится лимит API и не обещается ускоренный обход Googlebot.

## 5. Измерение результата

Главные показатели: **Google Search clicks, impressions, небрендовые целевые запросы, индексируемые коммерческие страницы**. Дополнительный — реально полученные заявки; без работающего серверного приёма лидов и счётчика аналитики их конверсию нельзя достоверно вычислить.

Численные оценки чужого органического трафика не подтверждены; мониторинг чужих title/H1 и URL не заменяет Semrush/Ahrefs.

Нельзя считать индексацию = позиции = трафик = заявки. Новые страницы должны иметь технически полезный уникальный материал, связь с референсами и понятный способ связаться.

## 6. Личные данные на сайте

На главной сейчас работает **mailto-форма**, которая не отправляет заявку на сервер. В опубликованном тексте политики обработки данных остались шаблонные реквизиты оператора. Перед подключением хранения заявок через Netlify Forms или иной серверный сервис нужно подтвердить оператора и согласовать реальную политику, условия обработки и уведомления. Нельзя заявлять доставку писем до успешного теста формы.

Все токены и service account остаются только в GitHub Actions Secrets, никакие ключи не публикуются в репозитории или чатах.
