## Внесённые изменения

1. /cip-moyka-otchety-scada/ — собственная инженерная схема записи «цикл, фаза, измерение, качество данных, отклонение». Генератор CSV в браузере: шапка, одна явно условная строка и 12 пустых строк. Ни одного заданного технологического норматива или реального результата мойки.
2. /avtomatizaciya-molochnogo-proizvodstva/ — конкретные PLC/SCADA/MES интерфейсы для приёмки, пастеризации, танков, CIP и передачи производственных событий; ссылка на шаблон.
3. /blog/fat-io-testy-pnr-asu-tp/ — контекстные внутренние ссылки на молочную автоматизацию и шаблон CIP из индексируемого технического руководства.
4. README.md — естественная публичная ссылка на бесплатный инженерный ресурс.
5. seo/competitors.json — два дополнительных публичных конкурентных URL; заголовки и содержание, а не чужие цифры трафика.

Сохраняем V6, canonical, число 49 URL. В sitemap lastmod изменён только для трёх фактически обновлённых страниц. Нет новых страниц, cookies, серверной заявки и отправки данных клиента. Программный журнал не доказывает санитарную чистоту и не подменяет технологическую валидацию.

## Проверки и измерение

- Static SEO integrity и V6 Playwright на мобильных/десктопных ширинах.
- Новый браузерный тест CIP CSV: download, имя файла, UTF-8 BOM, 14 строк без завершающей пустой, заголовки, условный пример, подтверждение клика.
- Проверить Timeweb SHA по https://dlvautomation.ru/dlv-deploy-revision.txt отдельно от GitHub main и GitHub Pages. При сетевых тайм-аутах нужен анализ логов; это не доказательство блокировки Googlebot.
- Сравнивать следующие непересекающиеся 7-дневные периоды Google Search Console по CIP/FAT/молочной/пищевой страницам. Данные Яндекса учитывать только после появления реальной статистики.
- Ни просмотры, ни переходы, ни индексирование не обещать и не приписывать новым текстам до фактического измерения.

Главная цель — релевантные запросы на программирование и интеграцию промышленного ПО, а не количество текстов.
