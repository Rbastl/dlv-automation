## Обоснование

- У DLV уже опубликованы самостоятельные URL по RS-485/Modbus RTU, калькулятору регистров Modbus RTU/TCP и интеграции оборудования. Дублирующие страницы создают риск конкуренции собственных URL.
- В публичном блоге [avtomatika.ru](https://avtomatika.ru/blog?type=%23Modbus) представлены отдельные руководства по Modbus Poll, RTU-сетям, RS-485 и диагностике обмена. Это *наблюдаемая структура тем*, а не подтверждённое число посещений. Проверенная страница конкурента: https://avtomatika.ru/blog/modbus-poll-kak-polzovatsya .
- Прямой коммерческий конкурент https://rusautomation.ru/services/programmirovanie/ включает программирование ПЛК, SCADA, Modbus, интеграции и доработку существующего ПО.
- Технические первоисточники: https://www.modbus.org/modbus-specifications и https://www.m.modbustools.com/mbpoll-user-manual.html . Данные с чужих сайтов не копируются; матрица диагностики DLV — самостоятельная инженерная структура.

## Проверки до публикации

1. GitHub CI: статическая SEO-целостность (49 URL, canonical, H1, внутренние ссылки) и браузерный V6 Playwright на мобильных и десктопных ширинах.
2. Проверить работоспособность нового якоря `#modbus-poll-diagnostics` с калькулятора и страницы услуги.
3. Сверить GitHub main SHA с `https://dlvautomation.ru/dlv-deploy-revision.txt` на **основном Timeweb**. Успешные GitHub Pages и CI не являются подтверждением публикации Timeweb.
4. Отдельно проверить `robots.txt`, `sitemap.xml`, HTTPS и повторяющиеся тайм-ауты извне. Не утверждать блокировку Googlebot/YandexBot только по GitHub Runner.
5. После обхода поисковиком оценить GSC/Яндекс по непересекающимся 7-дневным окнам, целевым поисковым запросам, CTR и реальным обращениям (когда появится корректная атрибуция).

## Следующая очередь после замеров

1. **Коммерческие:** проверить индексацию `/modernizaciya-asu-tp/`, `/outsourcing-asu-tp/`, `/avtomatizaciya-pishchevogo-proizvodstva/`. Пока не исправлена доступность/индексация, не плодить соседние почти одинаковые страницы.
2. **SCADA:** на существующей `/scada-hmi/` проверить наблюдаемые запросы про разработку проектов HMI/SCADA. Не повторять уже добавленные блоки о проверках тревог, архивов и цене без новой технической пользы.
3. **Modbus:** сначала подтвердить обнаружение/индексацию страницы RS-485 и интерес к её новому разделу; не дублировать учебник Modbus Poll.
4. **Внешние ссылки:** отраслевые каталоги и оригинальные инженерные материалы только с соблюдением правил площадок, без покупки массовых ссылок и выдуманных партнёрств.

**Ограничения:** точные посетители, доля покупателей и конверсия конкурентов неизвестны; поисковая видимость конкурента не равна его посещаемости. Эффект новых текстов не измерен до обхода и появления свежих поисковых данных.
